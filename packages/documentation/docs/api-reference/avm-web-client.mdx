## Static Methods

### `init([options])`

> Initializes the AVM web client object. If no options are supplied, a default configuration is used.

#### Parameters

| Name    | Type                                                                              | Required | Default | Description                                    |
|---------|-----------------------------------------------------------------------------------|----------|---------|------------------------------------------------|
| options | [`IAVMWebClientInitOptions`](../api-reference/types.mdx#iavmwebclientinitoptions) | no       | -       | An object to change the initial configuration. |

#### Returns

| Type                                                      | Description                           |
|-----------------------------------------------------------|---------------------------------------|
| [`AVMWebClient`](../api-reference/types.mdx#avmwebclient) | An initialized AVM web client object. |

## Methods

### `authenticate(params)`

> Sends a request to authenticate the client with a provider.

#### Parameters

| Name   | Type                                                                        | Required | Default | Description                                                              |
|--------|-----------------------------------------------------------------------------|----------|---------|--------------------------------------------------------------------------|
| params | [`IAuthenticationParams`](../api-reference/types.mdx#iauthenticationparams) | yes      | -       | Params that specify which provider, signer and the data to authenticate. |

#### Returns

| Type     | Description                    |
|----------|--------------------------------|
| `string` | the ID of the request message. |

### `disable([params])`

> Sends a request to remove the client from a provider.

#### Parameters

| Name   | Type                                                          | Required | Default | Description                                                             |
|--------|---------------------------------------------------------------|----------|---------|-------------------------------------------------------------------------|
| params | [`IDisableParams`](../api-reference/types.mdx#idisableparams) | yes      | -       | Params that specify which provider,network and/or specific session IDs. |

#### Returns

| Type     | Description                    |
|----------|--------------------------------|
| `string` | the ID of the request message. |

### `discover()`

> Sends a request to get information relating to available providers. This should be called before interacting with any providers to ensure networks and methods are supported.

#### Returns

| Type     | Description                    |
|----------|--------------------------------|
| `string` | the ID of the request message. |

### `enable([params])`

> Enables to a client with a provider. If the network is specified, only that **MAY** be network enabled.

#### Parameters

|--------|-------------------------------------------------------------|----------|---------|------------------------------------------------------|
| params | [`IEnableParams`](../api-reference/types.mdx#ienableparams) | no       | -       | Params that specify the provider and/or the network. |

#### Returns

| Type     | Description                    |
|----------|--------------------------------|
| `string` | the ID of the request message. |
