## Static Methods

### `init([options])`

> Initializes the AVM web provider object. If no options are supplied, a default configuration is used.

#### Parameters

| Name    | Type                                                                                  | Required | Default | Description                                    |
|---------|---------------------------------------------------------------------------------------|----------|---------|------------------------------------------------|
| options | [`IAVMWebProviderInitOptions`](../api-reference/types.mdx#iavmwebproviderinitoptions) | no       | -       | An object to change the initial configuration. |

#### Returns

| Type                                                          | Description                             |
|---------------------------------------------------------------|-----------------------------------------|
| [`AVMWebProvider`](../api-reference/types.mdx#avmwebprovider) | An initialized AVM web provider object. |
