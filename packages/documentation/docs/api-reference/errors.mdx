## VIP-03-0027 Errors

| Code | Name                                                                                            | Summary                                                                                                                                                                              |
|------|-------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 4000 | [`VIP030027UnknownError`](#vip030027unknownerror)                                               | The default error response, usually indicates something is not quite right.                                                                                                          |
| 4001 | [`VIP030027MethodCanceledError`](#vip030027methodcancelederror)                                 | When a user has rejected the method.                                                                                                                                                 |
| 4003 | [`VIP030027MethodNotSupportedError`](#vip030027methodnotsupportederror)                         | The specified provider does not exist.                                                                                                                                               |

### `VIP030027UnknownError`

This error is the default error and serves as the "catch all" error. This usually occurs when something has happened that is outside the bounds of graceful handling. You can check the `UnknownError.message` string for more information.

#### Properties

| Name    | Type     | Value | Description                      |
|---------|----------|-------|----------------------------------|
| code    | `number` | 4000  | A canonical code for this error. |
| message | `string` | -     | A human readable message.        |

### `VIP030027MethodCanceledError`

This error is thrown when a user has rejected or canceled the requested action on the wallet. For example, the user decides to cancel the signing of a transaction.

#### Properties

| Name    | Type     | Value | Description                                                                                                   |
|---------|----------|-------|---------------------------------------------------------------------------------------------------------------|
| code    | `number` | 4001  | A canonical code for this error.                                                                              |
| message | `string` | -     | A human readable message.                                                                                     |
| method  | `string` | -     | The name of the method that is not supported.                                                                 |
| vcic    | `string` | -     | The provider's base64 encoded public key credential that conforms to the [VIP-03-0026][vip-03-0026] standard. |

### `VIP030027MethodNotSupportedError`

This can be thrown by most [`AVMWebClient`](avm-web-client.mdx#methods) methods and indicates that the provider does not support the requested method.

| vcic    | `string` | -     | The provider's base64 encoded public key credential that conforms to the [VIP-03-0026][vip-03-0026] standard. |

### `VIP030027NetworkNotSupportedError`

This error is thrown when a provided genesis hash is not supported by the wallet.

#### Properties

| Name          | Type       | Value | Description                                                                                                   |
|---------------|------------|-------|---------------------------------------------------------------------------------------------------------------|
| code          | `number`   | 4004  | A canonical code for this error.                                                                              |
| genesisHashes | `string[]` | -     | The genesis hashes of the networks that are not supported.                                                    |
| message       | `string`   | -     | A human readable message.                                                                                     |
| vcic          | `string`   | -     | The provider's base64 encoded public key credential that conforms to the [VIP-03-0026][vip-03-0026] standard. |

### `VIP030027UnauthorizedSignerError`

This error is thrown when a provided account has been specified, but the provider has not given permission to use that account as a signer.

#### Properties

| Name    | Type     | Value | Description                                                                                                   |
|---------|----------|-------|---------------------------------------------------------------------------------------------------------------|
| code    | `number` | 4100  | A canonical code for this error.                                                                              |
| message | `string` | -     | A human readable message.                                                                                     |
| signer  | `string` | -     | The address (public key) of the signer that is not authorized.                                                |
| vcic    | `string` | -     | The provider's base64 encoded public key credential that conforms to the [VIP-03-0026][vip-03-0026] standard. |

### `VIP030027FailedToSignTransactionsError`

This error is thrown when some transactions failed to sign the provided transactions.

#### Properties

| Name          | Type                                 | Value | Description                                                                                                                                                                           |
|---------------|--------------------------------------|-------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| code          | `number`                             | 4300  | A canonical code for this error.                                                                                                                                                      |
| message       | `string`                             | -     | A human readable message.                                                                                                                                                             |
| successTxnIDs | <code>(string  &#124; null)[]</code> | -     | This will correspond to the `stxns` list sent in `postTxns` and will contain the ID of those transactions that were successfully committed to the blockchain, or null if they failed. |
| vcic          | `string`                             | -     | The provider's base64 encoded public key credential that conforms to the [VIP-03-0026][vip-03-0026] standard.                                                                         |

## ARC-0060 Errors

| Type                       | Name                                                            | Summary                                                                                                              |
|----------------------------|-----------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------|
| `ERROR_FAILED_DOMAIN_AUTH` | [`ARC0060FailedDomainAuthError`](#arc0060faileddomainautherror) | When authenticating data if the `authenticationData` field does not match the SHA-256 hash of the client's `domain`. |

### `ARC0060FailedDomainAuthError`

This error is thrown when authenticating data and the `authenticationData` field does not contain the SHA-256 hash of the client's `domain`.

#### Properties

| Name    | Type     | Value                      | Description                     |
|---------|----------|----------------------------|---------------------------------|
| message | `string` | -                          | A human readable message.       |
| type    | `string` | `ERROR_FAILED_DOMAIN_AUTH` | A canonical type for the error. |

### `ARC0060InvalidScopeError`

This error is thrown when signing typed data and the supplied `scope` is not supported.

#### Properties

| Name    | Type                    | Value                 | Description                     |
|---------|-------------------------|-----------------------|---------------------------------|
| message | `string`                | -                     | A human readable message.       |
| scope   | `string` \| `undefined` | -                     | The requested scope.            |
| type    | `string`                | `ERROR_INVALID_SCOPE` | A canonical type for the error. |

### `ARC0060InvalidSignerError`

This error is thrown when signing typed data and the supplied `signer` has not been given permission.

#### Properties

|---------|-------------------------|------------------------|---------------------------------|
