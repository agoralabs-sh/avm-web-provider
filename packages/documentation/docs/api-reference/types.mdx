## Params

### `IAuthenticationParams`

| Name               | Type     | Required | Default | Description                                                                                               |
|--------------------|----------|----------|---------|-----------------------------------------------------------------------------------------------------------|
| authenticationData | `string` | yes      | -       | A base64 encoded string of the authentication data.                                                       |
| data               | `string` | yes      | -       | A base64 encoded string of some arbitrary data to be used to authenticate.                                |
