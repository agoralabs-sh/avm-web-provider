## VIP-03-0027

### `createChallenge()`

> Convenience function to create a base64 encoded random 32-byte challenge that can be used in requests.

#### Returns

| Type     | Description                                 |
|----------|---------------------------------------------|
| `string` | A base 64 encoded random 32-byte challenge. |

## ARC-0060

### `signTypedData(options)`

> Signs some typed data using the [ARC-0060](https://arc.algorand.foundation/ARCs/arc-0060) standard.

#### Parameters

| Name    | Type                                                         | Required | Default | Description                                                                                 |
|---------|--------------------------------------------------------------|----------|---------|---------------------------------------------------------------------------------------------|
| options | [`ISignTypedDataOptions`](./types.mdx#isigntypeddataoptions) | yes      | -       | The authentication data, the data, the domain, the private key of the signer and the scope. |

#### Returns

| Type         | Description                                          |
|--------------|------------------------------------------------------|
| `Uint8Array` | The signature of the hashed data based on the scope. |

### `verifyTypedData(options)`

> Verifies some signed typed data.

#### Parameters

| Name    | Type                                                             | Required | Default | Description                                                                    |
|---------|------------------------------------------------------------------|----------|---------|--------------------------------------------------------------------------------|
| options | [`IVerifyTypedDataOptions`](./types.mdx#iverifytypeddataoptions) | yes      | -       | The authentication data, the data, the public key of the signer and the scope. |

#### Returns

| Type      | Description                                                                  |
|-----------|------------------------------------------------------------------------------|
| `boolean` | True if the signature is signed by the supplied public key, false otherwise. |
