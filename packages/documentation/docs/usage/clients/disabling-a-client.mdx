# Disabling a Client

## Overview

The disable method is not required for providers to implement. However, it is useful for providers that have a sessioning system in place when a client has previously called [`enable()`](../../api-reference/avm-web-client#enableparams).

The aim of the disable method is for clients to request that these sessions be removed from the provider.

## Disabling the client with a provider

Assuming a client has been [enabled](enabling-a-client), a request can be sent to disable a client with a provider using:

<Tabs
  defaultValue="javascript"
  values={[
    { label: 'Javascript', value: 'javascript' },
    { label: 'TypeScript', value: 'typescript' },
  ]}>
  <TabItem value="javascript">

  ```js
  client.onDisable(({ error, result }) => {
    if (error) {
      console.error('error:', error);

      return;
    }

    console.log(result);
    /*
    {
      genesisHash: 'SGO1GKSzyE7IEPItTxCByw9x8FmnrCDexi9/cOUJOiI=',
      genesisID: 'testnet-v1.0',
    }
    */
  });

  // send a disable request
  client.disable({
    vcic: 'q5dQ...',
  });
  ```

  </TabItem>
  <TabItem value="typescript">

  ```typescript
  client.onDisable(({ error, result }) => {
    if (error) {
      console.error('error:', error);

      return;
    }

    console.log(result);
    /*
    {
      genesisHash: 'SGO1GKSzyE7IEPItTxCByw9x8FmnrCDexi9/cOUJOiI=',
      genesisID: 'testnet-v1.0',
    }
    */
  });

  // send a disable request
  client.disable({
    vcic: 'q5dQ...',
  });
  ```

  </TabItem>
</Tabs>

:::caution

If any providers do not support the `disable` method, then a [`VIP030027MethodNotSupportedError`](/api-reference/errors#vip030027methodnotsupportederror) **SHOULD** be returned.

:::

## Disabling the client with a specific network

To disable the client with a specific network, the genesis hash of the network can be specified in the params:

<Tabs
  defaultValue="javascript"
  values={[
    { label: 'Javascript', value: 'javascript' },
    { label: 'TypeScript', value: 'typescript' },
  ]}>
  <TabItem value="javascript">

  ```js
  client.onDisable(({ error, result }) => {
    if (error) {
      console.error('error:', error);

      return;
    }

    console.log(result);
    /*
      genesisHash: 'SGO1GKSzyE7IEPItTxCByw9x8FmnrCDexi9/cOUJOiI=',
      genesisID: 'testnet-v1.0',
    }
    */
  });

  // send a disable request
  client.disable({
    params: {
      genesisHash: 'SGO1GKSzyE7IEPItTxCByw9x8FmnrCDexi9/cOUJOiI=',
    },
    vcic: 'q5dQ...',
  });
  ```

  </TabItem>
  <TabItem value="typescript">

    }
    */
  });

  // send a disable request
  client.disable({
    params: {
      genesisHash: 'SGO1GKSzyE7IEPItTxCByw9x8FmnrCDexi9/cOUJOiI=',

  </TabItem>

:::caution

If the network is specified, and the provider does not support the network, then a [`VIP030027NetworkNotSupportedError`](/api-reference/errors#vip030027networknotsupportederror) **SHOULD** be returned.

:::
