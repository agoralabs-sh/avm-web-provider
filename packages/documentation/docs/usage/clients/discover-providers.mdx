## Overview

For clients to identify providers, clients can send a `discover` request and providers will respond with their VCIC, any supported networks as well as the supported capabilities (methods) for each network.

## Discovering providers

After [initialization](getting-started), a client can start listening to `discover` messages. The callback passed will be called everytime a `discover` message is responded to by a provider.
