# Enabling a Client

<TOCInline
  maxHeadingLevel={4}
  toc={toc}
/>

## Overview

Before a client can start interacting with a provider, the provider will **MAY** need to enable the client. This will achieve two things:

* if necessary, it will authorize the client with the provider; and
* it will get a list of the authorized accounts available to the client.

:::note

It should be safe to call [`enable()`](../../api-reference/avm-web-client.mdx#enableparams). as many times as the client needs; the provider should assume this.

:::

:::caution

The definition of "enabling" for a provider can mean different things to different providers, but it is highly **RECOMMENDED** that a client first run [`enable()`](../../api-reference/avm-web-client.mdx#enableparams) before attempting any signing/post methods.

:::

## Enabling the client with a provider

After [initialization](./getting-started.mdx), simply call:

## Enabling a client for a specific network

To target a specific network, a client can pass the genesis hash of the network in the params:
