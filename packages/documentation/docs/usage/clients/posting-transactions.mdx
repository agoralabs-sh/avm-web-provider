## Overview

Providers, if supported, can commit transactions to the network using their connection to a node.

## Posting transactions to the network using a provider

<Tabs
  defaultValue="javascript"
  values={[
    { label: 'Javascript', value: 'javascript' },
    { label: 'TypeScript', value: 'typescript' },
  ]}>
  <TabItem value="javascript">

  ```js
  client.onPostTransactions(({ error, result }) => {
    if (error) {
      console.error('error:', error);

      return;
    }

    console.log(result);
    /*
    {
      txnIDs: [
        'OKU6A2Q...',
      ],
    }
    */
  });

  // send a post transactions request
  client.postTransactions({
    params: {
      stxns: [
        'gqNzaWfEQ...',
      ],
    },
    vcic: 'q5dQ...',
  });
  ```

  </TabItem>
  <TabItem value="typescript">

  ```typescript
  client.onPostTransactions(({ error, result }) => {
  ```

  </TabItem>
</Tabs>

:::caution

If this method is not supported, then a [`VIP030027MethodNotSupportedError`](/api-reference/errors#vip030027methodnotsupportederror) **SHOULD** be returned.

:::

:::caution

If the transactions fail to be accepted by the network, then a [`VIP030027FailedToPostSomeTransactionsError`](/api-reference/errors#vip030027failedtopostsometransactionserror) **SHOULD** be returned.

:::
