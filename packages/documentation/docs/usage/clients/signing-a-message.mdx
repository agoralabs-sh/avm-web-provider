## Overview

Providers, if supported, can sign an arbitrary string using UTF-8 encoding. The resulting string **SHOULD** be verified using [`alogosdk.verfiyBytes`](https://algorand.github.io/js-algorand-sdk/functions/verifyBytes.html).

## Signing a message

<Tabs
  defaultValue="javascript"
  values={[
    { label: 'Javascript', value: 'javascript' },

  ]}>
  <TabItem value="javascript">

  ```js
  client.onSignMessage(({ error, result }) => {
    if (error) {
      console.error('error:', error);

      return;
    }

    console.log(result);
    /*
    {
      signature: 'gqNzaWfEQ...',
      signer: 'P3AIQVDJ2CTH54KSJE63YWB7IZGS4W4JGC53I6GK72BGZ5BXO2B2PS4M4U',
    }
    */
  });

  // send a sign message request
  client.signMessage({
    params: {
      message: 'Hello humie!',
      signer: 'P3AIQVDJ2CTH54KSJE63YWB7IZGS4W4JGC53I6GK72BGZ5BXO2B2PS4M4U',
    },
    vcic: 'q5dQ...',
  });
  ```

:::caution
