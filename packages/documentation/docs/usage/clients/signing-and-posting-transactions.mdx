## Overview

Providers may have the functionality to both sign & post transactions. This method allows clients to avoid using the previous methods of [signing transactions](./signing-transactions.mdx) and [posting transactions](./posting-transactions.mdx) separately and simply performs the functionality of these previous methods within one method.

## Sending transactions to be signed & posted to the provider

:::note

See [signing transactions](./signing-transactions.mdx) for more examples.

:::

  ```js
  const algosdk = require('algosdk');

  // create a transaction
  try {
    const algodClient = new algosdk.Algodv2(
      'aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa',
      'http://localhost',
      '4001',
    );
    const encoder = new TextEncoder();
    const suggestedParams = await algodClient.getTransactionParams().do();
    const transaction = algosdk.makePaymentTxnWithSuggestedParamsFromObject({
      amount: algosdk.algosToMicroalgos(1),
      from: 'P3AIQVDJ2CTH54KSJE63YWB7IZGS4W4JGC53I6GK72BGZ5BXO2B2PS4M4U',
      note: encoder.encode('Hello Humie!'),
      suggestedParams,
      to: '6GT6EXFDAHZDZYUOPT725ZRWYBZDCEGYT7SYYXGJKRFUAG5B7JMI7DQRNQ',
    });
    const transactionBytes = transaction.toByte();
  } catch (error) {
    // handle error
  }

  client.onSignAndPostTransactions(({ error, result }) => {
    if (error) {
      console.error('error:', error);

      return;
    }

    console.log(result);
    /*
    {
      txnIDs: [
        'OKU6A2Q...',
      ],
    }
    */
  });

  // send a sign and post transactions request
  client.signAndPostTransactions({
    params: {
      txns: [
        {
          txn: btoa(String.fromCodePoint(...transactionBytes)), // convert to base64 string
        },
      ],
    },
    vcic: 'q5dQ...',
  });
  ```

:::caution

If this method is not supported, then a [`VIP030027MethodNotSupportedError`](../../api-reference/errors.mdx#vip030027methodnotsupportederror) **SHOULD** be returned.

:::

:::caution

If there is a group of atomic transactions, but the computed group ID is invalid, then a [`VIP030027InvalidGroupIdError`](../../api-reference/errors.mdx#vip030027invalidgroupiderror) **SHOULD** be returned.

:::

:::caution

If any of the transactions are malformed, then a [`VIP030027InvalidInputError`](../../api-reference/errors.mdx#vip030027invalidinputerror) **SHOULD** be returned.

:::

:::caution

If the transactions fail to be accepted by the network, then a [`VIP030027FailedToPostSomeTransactionsError`](../../api-reference/errors.mdx#vip030027failedtopostsometransactionserror) **SHOULD** be returned.

:::
