## Installation

### Using a package manager

Use your favourite package manager to install:

```bash npm2yarn
npm install --save @agoralabs-sh/avm-web-provider
```

### Download via a CDN

Include the minified browser bundle directly in your HTML like so:

```html
<html>
  ...
  <script src="https://github.com/agoralabs-sh/avm-web-provider/releases/latest/download/avm-web-provider.min.js"></script>
  ...
</html>
```


## Initialization

To initialize the AVM web provider, a VCIC will need to be provided:

:::note

The Verifiable Compact Identity Credential (VCIC) is a special identifier that allows clients to identify a provider and verify any provider messages. See the [VIP-03-0026](https://vips.voi.community/03/0026) for details on how a VCIC is implemented.

:::
