# Responding to Authentication Requests

<TOCInline

## Overview

If the provider supports it, a provider can accept authentication a requests from the client using the [ARC-0060](https://arc.algorand.foundation/ARCs/arc-0060) specification.

:::info

When signing data, it **MUST** be signed using the [ARC-0060](https://arc.algorand.foundation/ARCs/arc-0060) specification. The utility method [`signTypedData`](../../api-reference/utilities.mdx#signtypeddataoptions) can be used to sign the data.

:::

## Responding to an authentication request

Once our provider object has been initialized, we can simply listen to events and respond:

<Tabs
  defaultValue="javascript"
  values={[
    { label: 'Javascript', value: 'javascript' },
    { label: 'TypeScript', value: 'typescript' },
  ]}>
  <TabItem value="javascript">

  ```js
  const { generateAccount, secretKeyToMnemonic, seedFromMnemonic } = require('algosdk');

  const account = generateAccount();

  provider.onAuthenticate(({ challenge, params }) => {
    const privateKey = seedFromMnemonic(
      secretKeyToMnemonic(account.sk)
    );
    const signature = signTypedData({
      authenticationData: Buffer.from(params.authenticationData, 'base64'),
      data: Buffer.from(params.data, 'base64'),
      domain: 'avm-web-provider.agoralabs.sh', // client domain
      privateKey,
      scope: 1, // AUTH
    });

    return {
      result: {
        signature: Buffer.from(signature).toString('base64'),
        signer: account.addr,
      },
      signature: 'gqNzaWfEQ...', // this must be the result of the signing of the challenge using the vcic's private key
      vcic: vcic.config.credential.toString(),
    };
  });
  ```

  </TabItem>

## Responding to an authentication request with a specific signer

The `authenticate` request allows a signer to be specified. This is specified by the `params.signer` parameter.

<Tabs
  defaultValue="javascript"
  values={[
    { label: 'Javascript', value: 'javascript' },
    { label: 'TypeScript', value: 'typescript' },
  ]}>
  <TabItem value="javascript">

  ```js
  const { ARC0060InvalidSignerError } = require('@agoralabs-sh/avm-web-provider');
  const { generateAccount, secretKeyToMnemonic, seedFromMnemonic } = require('algosdk');

  const account = generateAccount();

  provider.onAuthenticate(({ challenge, params }) => {
    let privateKey;
    let signature;

    // if the signer has been defined, and it is not allowed, it is recommended that you throw and error
    if (signer && account.addr !== signer) {
      throw new ARC0060InvalidSignerError({
        message: 'invalid signer',
        signer,
      });
    }

    privateKey = seedFromMnemonic(
      secretKeyToMnemonic(account.sk)
    );
    signature = signTypedData({
      authenticationData: Buffer.from(params.authenticationData, 'base64'),
      data: Buffer.from(params.data, 'base64'),
      domain: 'avm-web-provider.agoralabs.sh', // client domain
      privateKey,
      scope: 1, // AUTH
    });

    return {
      result: {
        signature: Buffer.from(signature).toString('base64'),
        signer: account.addr,
      },
      signature: 'gqNzaWfEQ...', // this must be the result of the signing of the challenge using the vcic's private key
      vcic: vcic.config.credential.toString(),
    };
  });
  ```

  </TabItem>
