# Responding to Disable Requests

<TOCInline
  maxHeadingLevel={4}
  toc={toc}

## Overview

Providers that implement a session for a client, a disable request can be called by a client that instructs the provider to remove the client's session.

## Responding to a disable request

Once the provider object has been initialized, simply listen to events and respond:

<Tabs
  defaultValue="javascript"
  values={[
    { label: 'Javascript', value: 'javascript' },
    { label: 'TypeScript', value: 'typescript' },
  ]}>
  <TabItem value="javascript">

  ```js
  provider.onDisable(({ challenge }) => {
    // ... remove all sessions

    return {
      result: {
        genesisHash: 'SGO1GKSzyE7IEPItTxCByw9x8FmnrCDexi9/cOUJOiI=',
        genesisID: 'testnet-v1.0',
        sessionIDs: ['02657eaf-be17-4efc-b0a4-19d654b2448e'], // optional
      },
      signature: 'gqNzaWfEQ...', // this must be the result of the signing of the challenge using the vcic's private key
      vcic: vcic.config.credential.toString(),
    };
  });
  ```

  </TabItem>
  <TabItem value="typescript">

  ```typescript

    // ... remove all sessions

    return {
      result: {
        genesisHash: 'SGO1GKSzyE7IEPItTxCByw9x8FmnrCDexi9/cOUJOiI=',

        sessionIDs: ['02657eaf-be17-4efc-b0a4-19d654b2448e'], // optional
      },
      signature: 'gqNzaWfEQ...', // this must be the result of the signing of the challenge using the vcic's private key
  ```

  </TabItem>
</Tabs>

:::note

If no network or session IDs have been specified, you can assume all sessions for this client should be removed.

:::

:::caution

If this method is not supported, then a [`VIP030027MethodNotSupportedError`](../../api-reference/errors.mdx#vip030027methodnotsupportederror) **SHOULD** be thrown.

:::

## Responding to a disable request for a specific network

The `disable` request allows the client to specify the network. This is specified by the `params.genesisHash` parameter.

<Tabs
  defaultValue="javascript"
  values={[
    { label: 'Javascript', value: 'javascript' },
    { label: 'TypeScript', value: 'typescript' },
  ]}>
  <TabItem value="javascript">

  ```js
  const { VIP030027NetworkNotSupportedError } = require('@agoralabs-sh/avm-web-provider');

  const genesisHash = 'SGO1GKSzyE7IEPItTxCByw9x8FmnrCDexi9/cOUJOiI=';

  provider.onDisable(({ challenge, params }) => {
    // if the genesis hash has been defined, it is recommended that you throw and error
    if (param.genesisHash && param.genesisHash !== genesisHash) {
      throw new VIP030027NetworkNotSupportedError({
        genesisHashes: [param.genesisHash],
        vcic: vcic.config.credential.toString(),
      });
    }

    // ... remove all sessions for the network

    return {
      result: {
        genesisHash,
        genesisID: 'testnet-v1.0',
        sessionIDs: ['02657eaf-be17-4efc-b0a4-19d654b2448e'], // optional
      },
      signature: 'gqNzaWfEQ...', // this must be the result of the signing of the challenge using the vcic's private key
      vcic: vcic.config.credential.toString(),
    };
  });
  ```

  </TabItem>

## Responding to specific session IDs

A requesting client can specify a particular session. This can be used instead of specifying the network, or if the provider supports multiple sessions.

<Tabs
  defaultValue="javascript"
  values={[
    { label: 'Javascript', value: 'javascript' },
    { label: 'TypeScript', value: 'typescript' },
  ]}>
  <TabItem value="javascript">

  ```js
  const sessionID = '2802dff6-930e-4f79-8f67-ba9d41e88cf8';

  provider.onDisable(({ challenge, params }) => {
    if (params && params.sessionIds.indexOf(sessionId) >= 0) {
      // ... remove sessions specified in the session ids list

    return {
      result: {
        genesisHash: 'SGO1GKSzyE7IEPItTxCByw9x8FmnrCDexi9/cOUJOiI=',
        genesisID: 'testnet-v1.0',
        sessionIDs: [sessionID], // optional
      },
      signature: 'gqNzaWfEQ...', // this must be the result of the signing of the challenge using the vcic's private key
      vcic: vcic.config.credential.toString(),
    };
  });
  ```

  </TabItem>
  <TabItem value="typescript">
