<TOCInline

## Overview

For clients to identify providers, they will likely send a `discover` request. Responding to these request, a provider **MUST** return their VCIC, the supported networks as well as the supported capabilities (methods) for each network.

## Responding to a discover request

Once the provider object has been initialized, simply listen to events and respond:
