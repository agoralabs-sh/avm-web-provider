<TOCInline
  maxHeadingLevel={4}

## Overview

When receiving a request from the client, a provider can throw errors within the listener function and these errors will propagate back to the client's listener arguments.

  client.disable();

  // AVMWebProvider
  const { VIP030027MethodNotSupportedError } = require('@agoralabs-sh/avm-web-provider');

  provider.onDisable(({ params }) => {
    throw new VIP030027MethodNotSupportedError({
      method: 'disable',
      message: 'disable method is not supported',
      vcic: provider.config.credential.toString(),
    });
  });
